# Product

**Goal.** Before AI, software ideas were bounded by coding ability. AI removed that wall; the new bottleneck is *what to build*. IdeaForge lowers the creativity wall: user answers behavioral questions, hosted AI returns 3-5 concrete software-idea suggestions. Ideas only — no stack, no implementation.

**Users.** Devs and non-devs who can build with AI tools but run out of "what should I build". No login, no account.

**Scope boundary (what this project is NOT).**
- Not building software for the user.
- Not recommending stack/platform/tools.
- Not a chat; one-shot generation + refine + regenerate.

**DoD (whole project).** Fresh user completes 5-step wizard ≤3 min) → sees 3-5 AI-labeled structured ideas (problem/audience/name/description/why-now/differentiator/validate-path), zero tech-stack mentions → can thumbs-up/favorite/regenerate and refine any single idea.

**Success signal.** User says "never thought of that" / wants to build idea #2.
